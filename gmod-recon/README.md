# GMod Recon Android test APK

Standalone Android WebView map test build generated on a temporary isolated branch. This version packages 477 synthetic example GMod servers; **no live server discovery** and no exact address collection. Zoom, server clustering, filtering, Top 100, watchlist, and server inspection are implemented. Needs network access for MapLibre and CARTO base-map tiles. Original v0.1.1 fuller source lives in the previously supplied source ZIP and has not been replaced. Debug APK produced by GitHub Actions, not a release-signed build.
